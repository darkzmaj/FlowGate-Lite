# FlowGate Lite 1.0.8

FlowGate Lite now runs on Velocity as well as BungeeCord. One JAR for both. It also adds anonymous usage statistics and shows the right version.

An earlier 1.0.8 build without Velocity support was briefly released and then pulled. If you downloaded it, replace it with this one. Config files are compatible.

## What's new
- **Velocity 3.4+ and 4.x support.** Hub routing, balancing, health pings, quarantine, kick fallback, limbo with titles, `/hub`, slash-server commands, `/flowgate reload|status`, MOTD/hover and backend `Connect` policy all work on Velocity.
- **Anonymous usage statistics.** Once a day: an anonymous id, the version, the platform (`bungeecord` or `velocity`) and that it is a proxy. No IPs, server names or player data. Turn off with `metrics.enabled: false`.

## Fixes
- The startup log and `/flowgate status` show the real plugin version.
- Deleted example entries in `slash-servers`, `server-weights`, `server-names` and `motds` no longer come back.

## Velocity notes
- Set `bungee-plugin-message-channel = false` in `velocity.toml` if you want FlowGate's policy on backend `Connect` messages. FlowGate then handles only `Connect`; other BungeeCord subchannels are dropped.
- Velocity has no restricted-server flag, so restricted-access checks apply on BungeeCord only.
- Config folder on Velocity: `plugins/flowgate-lite/`.

## Compatibility
- Player-tested: Velocity 3.4.0 (Java 17), 3.5.1 (Java 21), 4.3.1 and 4.3.2-SNAPSHOT (Java 25), BungeeCord build 2111 and Waterfall build 615 (Java 21), each with Paper 1.21.11 backends and Minecraft 1.21.11 bot players.
- 28 unit tests pass.

## Installation / updating
Stop the proxy, back up the plugin folder, put **FlowGate-Lite-1.0.8.jar** in `plugins/` (remove the old JAR) and start the proxy. No config migration is needed; `metrics.enabled` defaults to true when missing. Check the SHA-256 file. Source archives are not installable plugins.

## Known limits
Not tested: high player counts, online mode, FlameCord and Velocity forks.
